# Pertamina Chatbot — Frontend

Dokumentasi lengkap mengenai arsitektur antarmuka pengguna (React + Vite), daftar seluruh komponen, dan mekanisme integrasi dengan backend FastAPI dapat dilihat pada berkas:

👉 [**README Dokumentasi Frontend Lengkap**](./frontend/README.md)

### Ringkasan Cepat
- **Direktori Proyek**: `Frontend/frontend/`
- **Jalankan Aplikasi**:
  ```powershell
  cd Frontend/frontend
  npm install
  npm run dev
  ```
- **Akses Antarmuka**: `http://localhost:5174/` (atau `5173`)
- **Backend API**: Berjalan di `http://127.0.0.1:8000`
